# Agent handoff

Treat this repository as a substantially implemented contract handoff, not a blank scaffold. Preserve the core boundary: semantic consensus classifies clause applicability; deterministic code resolves the final rule/exception outcome.

Do not convert this into a frontend, policy chatbot, generic text classifier, evidence oracle, correction graph, licensing graph or lock scheduler.

The implementation agent should run the supplied checks, fix real GenLayer/runtime issues, expand adversarial tests where appropriate, deploy to stable Studionet only after Direct Mode is green, prove typed consumer behavior with ExceptionGate, and document only evidence actually produced.
